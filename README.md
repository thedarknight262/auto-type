# CodeKata Auto Typer

A Chrome extension that automatically types code into the GUVI CodeKata editor.

## Features
- Instant paste
- Human-like slow typing
- Clear editor option
- Adjustable speed

## Installation

1. Open Chrome and go to: `chrome://extensions`
2. Turn **ON** Developer mode (top right)
3. Click **Load unpacked**
4. Select the `codekata-auto-typer` folder

## How to Use

1. Open any CodeKata problem
2. Click the **Code Editor** tab
3. Click the extension icon
4. Paste your code
5. Click **Type Code into Editor**

> Tip: Refresh the page (`F5`) if it doesn't work.

## Files Needed
- `manifest.json`
- `content.js`
- `popup.html`
- `popup.js`
